# Make quality decisions per whole can

A delivery can contain both usable and rejected milk, so a single delivery-wide decision would lose the detail needed to explain partial rejections. Each delivery therefore contains individual can entries with their own readings and whole-can decisions; partial delivery rejection means rejecting some cans, while splitting the contents of one can is outside the prototype scope. This keeps disputed quantities attributable to individual cans without introducing separate accepted and rejected portions within one can entry.
